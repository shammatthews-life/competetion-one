## Audit findings on historical evidence quality

- The README/report language “independent,” “exact,” “confirmed,” and “leaderboard score” is not itself provenance. Mode, code, selected input path, and file hashes decide the classification.
- Phase 1 exact reproduction and the V5 correlation replication are artifact replays/hybrid replays; those numerical results do not prove upstream retraining.
- Phase 3 report asserts a raw-independent final chain, but its source reads historical V17/V55/XGB cache files for final suite synthesis. This source/report contradiction is resolved in favor of the source.
- The final raw production execution proves the recovered V17/V55/XGB10/Anchor generator scripts can run on raw input. It does **not** make their predictions equivalent to the historical cache; the current Track1B score against champion was 0.8921289 Spearman.
- Some historical array comparisons are positional because `.npz`/`.npy` contain no IDs. They are not certified ID-aligned comparisons.
- The copied project history is available in Git; the original `D:\gci\champion` and `D:\gci\gemini` directories have no Git metadata. Historical commit-level source lineage cannot be recovered from those paths alone.
