# Technique Assessment Notes

This is a concise implementation note paired with `RESEARCH_REFERENCES.md`. Published evidence supports considering a method; it does not predict its value on this dataset.

| Method | Mechanism and dataset rationale | Historical attempt? | Required data | Leakage-safe validation | Cost / RTX 4050 | Benefit uncertainty |
|---|---|---|---|---|---|---|
| Financial ratio / interaction engineering | Expose ability-to-pay, collateral/credit, tenure and external-score interactions to tree splits | Yes: Hasan 669, V17/V55 views, XGB10 manifold, Phase 2 fee/product features | Existing raw application columns | Fold-invariant deterministic transformations; nested selection if labels influence choices | Low CPU preprocessing; model cost varies | Project evidence supports selected Phase 2 fee/key blocks, but does not support arbitrary new ratios |
| Nested smoothed target encoding | Estimate conditional risk for recurring decoded keys with shrinkage | Yes: Phase 2 and historical Bayesian/OOF encoding claims | Categorical/key fields and training labels | Nested OOF each train row; outer-train only for validation/test | Medium, CPU | Phase 2 is positive across two seeds; new variants uncertain |
| Frequency/count encoding | Capture repeated product/fee structures and category prevalence | Yes: Phase 2 fee decoder | Covariates only | Prefer fold-local counts; report pooled transductive arm separately | Very low CPU | Existing decoder ablation +0.00319 in the tested gate; exact transfer not guaranteed |
| Missingness regimes | Missing external bureau scores can define different risk regimes | Yes: Anchor74 EXT_SOURCE regimes; native missing splits in trees | EXT_SOURCE columns and missing flags | Learn any regime weights inside training folds; test group counts only descriptive | Low CPU/GPU | Historical/project rationale only; no new independent ablation yet |
| GBDT diversity | CatBoost handles categories; XGB/LightGBM provide different tree constraints/optimization | Yes: historical suites and Phase 2 | Raw features, fold-safe OOF | Same folds, seed and preprocessing; meta-model only on OOF | Medium; Cat/XGB GPU, LGBM CPU in present build | XGB phase lift was small/inconsistent; avoid broad ensemble tuning |
| TabM / ResNet | Dense neural representations / parameter-efficient ensemble may add non-tree inductive bias | Not evidenced as trained historical component in inspected sources | Numeric/categorical views, GPU Torch | Fold-only preprocessing, early stop on inner validation, independent seeds | High; torch absent and 6-GiB memory | Unknown; no AUC estimate |
| Rank/probit calibration | Monotonic rank mapping stabilizes scale before blending | Yes: EXP85 formula | OOF/test prediction vectors | Calculate transforms from each training-fold partition; never use outer labels in blend selection | Very low CPU | Historical recipe is known; it improves comparability but doesn't repair missing lineage |
| Transductive features | Unlabeled test covariates can inform frequencies/manifold | Yes: Phase 2 pooled counts and historical apex | Train/test covariates, no test labels | Paired fold-local versus pooled covariate arms; state deployment-specific assumption | Low/medium | Phase 2 sensitivity says fold-local nearly retains lift; other apex effects unverified |
| Graph/neighbor smoothing | Verified repeated borrowers or similar applicants may share structure | Described by Anchor74 sources | Exact ID/key attributes and permitted labels for training nodes | Fold-local graph; test-to-test only for unlabeled inference; negative controls | Medium, usually CPU | High uncertainty; low current priority due entity-link and leakage risk |
