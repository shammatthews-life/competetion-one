# Official Competition Rules Snapshot

- **Competition**: In-class Competition: Home Credit Default Risk | GCI Global 2026
- **Source Document**: `Competition/README.ipynb` & Omnicampus Submission Portal
- **Evaluation Metric**: ROC AUC (Area Under the Receiver Operating Characteristic curve)
- **Submission Requirements**:
  * Format: CSV file containing exactly two columns: `SK_ID_CURR`, `TARGET`.
  * Row Count: Exactly 61,500 test rows.
  * Evaluation: Public Leaderboard scoring on subset during competition; Private Leaderboard on entire test set at completion.
- **Honors / Outstanding Student Requirement**:
  > *"If you wish to be considered for Honors or Outstanding Student, you are required to submit code that can reproduce the CSV file you submitted."*
- **Data Policy**: Zero external datasets allowed. Only the supplied `train.csv` and `test.csv` may be utilized.
- **Manual Hand-Labeling Policy**: Strictly prohibited.
