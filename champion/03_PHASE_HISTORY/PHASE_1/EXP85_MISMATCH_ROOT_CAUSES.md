## 5. Root Cause 4: Multi-Seed & Checkpoint Stochasticity

Even within the 8-engine suite (V17 and V55), where the code architecture was faithfully followed:
- **LightGBM / XGBoost GPU Threading**: Non-deterministic floating-point reduction across CUDA warps introduces tiny variations ($10^{-5}$ to $10^{-4}$) at leaf value accumulation.
- **CatBoost Multi-Threading**: Parallel tree construction with multi-threading creates minor differences in split finding order.
- **Nelder-Mead Initialization**: The Nelder-Mead simplex algorithm is sensitive to input gradient perturbations. When OOF predictions differ by 1–2%, the optimal solver converges to slightly different engine weights.
