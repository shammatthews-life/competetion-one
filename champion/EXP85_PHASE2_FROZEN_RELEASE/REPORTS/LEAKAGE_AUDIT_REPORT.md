# Leakage and Validation Audit

## Result

The selected Phase 2 candidate passes the implemented leakage-safety checks for nested target encodings and candidate integrity. Phase 1 and Phase 2 use the entire unlabeled train/test covariate pool to derive fee-ratio frequency counts. This is transductive unsupervised preprocessing, not target leakage, and must remain part of the stated evaluation protocol.

No experiment used historical prediction caches as model features. Phase 3 does use Phase 2 model predictions as members of its three-model ensemble; those predictions are outputs of the raw-only Phase 2 experiment rather than historical caches.

## Target-label boundaries

- Raw rowwise features and the fee/product formula do not read `TARGET`.
- Tests explicitly change the labels while holding raw covariates fixed and verify that the decoded fee/product features stay unchanged.
- For each Phase 2 outer fold, training-row target encodings are generated by inner five-fold OOF encoding (seed 7). Each encoded row's mapping is fit on disjoint inner-training rows only.
- Outer validation and test encodings are fit using only the outer-training rows and labels. The encoder asserts that fit and apply indices do not overlap.
- A test changes labels on apply rows and verifies that the apply encodings remain identical.
- No target values from the validation fold or test set enter the encoding maps, and no validation/test labels are used for model selection, calibration, blend-weight optimization, or feature selection.
- Every one of the five outer fit/validation splits was recomputed from `StratifiedKFold(shuffle=True, seed=42)` and matched the saved Phase 2 and Phase 3 assignments exactly.

## Transductive feature caveat

Phase 1 computes rounded raw and fee-adjusted annuity/credit ratio counts on pooled train plus test covariates, and selects the decoded interpretation by comparing those counts. The target is removed before the pooled covariate set is assembled. Phase 2 reuses these derived keys for target encoding.

Consequences:

1. The original seed-42 CV score is evidence for this fixed competition train/test pool and its transductive feature recipe.
2. Held-out validation rows influence the pooled unlabeled frequency table used to build their own ratio features. No held-out labels are revealed, but that score alone is not an inductive estimate for an unrelated future cohort.
3. This caveat was tested on a second five-fold seed with fold-local frequency counts built only from each outer-training fold. The fold-local variant improved over a newly trained same-fold raw baseline on all five folds and scored 0.7709638204 versus 0.7711413866 for pooled frequencies. A controlled fold-local decoder ablation improved by 0.0031900392 OOF AUC on all five folds.
4. The selected original seed-42 candidate still uses pooled frequencies; the fold-local run is a sensitivity result and does not silently alter the frozen candidate.

## Model and prediction boundaries

- Phase 1 reads frozen baseline OOF metrics/predictions only to compare paired CV performance; its candidate model predictions are trained from raw inputs.
- Phase 2 recomputes its features and fits both model families on raw-derived features. Earlier phase artifacts are used as feature-builder/code lineage and comparison evidence, not as prediction features.
- Phase 3 fits XGBoost using raw-derived features and nested encodings. Its final three-model candidate additionally averages the Phase 2 LightGBM/CatBoost OOF/test predictions with XGBoost predictions. Those Phase 2 predictions are actual candidate dependencies, despite the Phase 3 summary field naming them `comparison_only_prediction_inputs`.
- The Phase 2 two-model candidate has no dependency on Phase 3 or historical prediction files and remains the selected candidate.

## Integrity checks run

`source/validate_experiment_artifacts.py` completed without fitting models. It verified all Phase 1/2/3 run output hashes (23/15/12 records), input hashes for train/test/sample (3 per run), saved two- and three-model blends, candidate CSV probability values, schemas, exact test/sample ID order, uniqueness, fold assignments, and recomputed OOF AUCs.

The three submissions contain 61,500 rows each, have exactly `SK_ID_CURR,TARGET`, have no duplicate IDs, match test ID order, and reproduce their stored probability arrays with maximum CSV-rounding difference below `5.1e-11`.

## Limitations

The lift has now repeated across two outer split seeds, but both use five-fold development CV and the experiments were conducted during model research. Treat it as repeatability evidence, not a guarantee of future-cohort performance or official leaderboard score. No fold labels enter their own target-encoding values; fold-local frequency sensitivity also limits the transductive caveat but does not replace the selected pooled-frequency candidate.

No official leaderboard evaluation was run. Correlation with a historical submission and any notebook text that prints a score are not official score evidence.
