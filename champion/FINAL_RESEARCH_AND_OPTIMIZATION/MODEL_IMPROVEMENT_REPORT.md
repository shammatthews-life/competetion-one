# Independent Model Improvement Report

## Outcome

The independent raw-only pipeline improved on its frozen development baseline using two feature additions evaluated on the same five stratified folds:

- Raw baseline fixed 50/50 LightGBM/CatBoost OOF AUC: **0.7625457907**.
- Fee/product feature experiment fixed 50/50 OOF AUC: **0.7648301137**.
- Nested-key-target-encoding experiment fixed 50/50 OOF AUC: **0.7715614423**.
- Improvement over the frozen baseline: **+0.0090156516 OOF AUC**.

Both individual models and the fixed blend improved on all five folds in the fee-feature experiment. Adding nested target encodings improved the fixed blend on all five folds versus the fee-feature model. This is meaningful development-CV progress, not an official competition score or proof of historical EXP85 reconstruction. The experiments share one CV seed; independent-seed replication is still needed before treating the magnitude as stable.

## Experiment sequence

| Experiment | Feature/model change | OOF AUC | Paired fold result | Device and elapsed time |
|---|---|---:|---|---|
| Frozen raw baseline | Rowwise features; LightGBM + CatBoost, 50/50 | 0.7625457907 | Reference | LightGBM CPU + CatBoost GPU; 736.7 s |
| Phase 1 | Add fee-decoded and product-tier features to both models | 0.7648301137 | Mean blend delta +0.0023017; 5/5 folds positive | LightGBM CPU + CatBoost GPU; 403.8 s |
| Phase 2 | Add nested, smoothed encodings for decoded ratio/product keys | 0.7715614423 | Mean blend delta +0.0067531 vs Phase 1; 5/5 positive | LightGBM CPU + CatBoost GPU; 331.0 s |
| Phase 3 | CUDA XGBoost on Phase 2 features; equal 1/3 three-model blend | 0.7716955766 | +0.0001341 full OOF vs Phase 2; 3/5 folds positive | XGBoost CUDA; 67.0 s |

Phase 3's small ensemble gain was inconsistent across folds, and XGBoost OOF prediction correlations were 0.9881 with LightGBM and 0.9740 with CatBoost. The three-model ensemble is not selected as the stable candidate. The selected candidate remains the fixed 50/50 Phase 2 blend; no weights were optimized against OOF labels.

## Training and lineage

All three new phases fit models from raw competition train/test CSV-derived features. The Phase 1 fee-frequency feature uses pooled, unlabeled train/test covariates; this transductive choice is disclosed and no targets enter the frequency decoder. Phase 2 target encodings are nested: outer-training rows receive inner OOF encodings; outer validation and test rows are encoded using outer-training labels only. Baseline/Phase 1 predictions are read only for post-hoc CV comparisons, never as training features.

The Phase 3 XGBoost model uses raw-derived Phase 2 features, but its equal-weight three-model candidate actually averages Phase 2 LightGBM/CatBoost OOF/test predictions with XGBoost predictions. The Phase 3 run summary incorrectly labels those arrays as `comparison_only_prediction_inputs`; source inspection and independent blend recomputation establish that they are real ensemble dependencies. They are generated by the independent raw-only Phase 2 experiment, not historical caches. The selected Phase 2 candidate does not depend on Phase 3 outputs.

CatBoost used GPU:0; LightGBM used CPU because the installed build has no supported GPU backend. XGBoost 3.4.1 used explicit `device=cuda`; saved booster configuration records `device=cuda:0` and `grow_gpu_hist`. No silent CPU fallback was enabled.

The repository's historical champion and the origin notebook were not changed. The new candidate remains a separate independent raw-data experiment; it does not replace the historical 0.801340 champion.

## Limits and next step

The fixed folds provide paired evidence but are still one CV realization. Before submission, replicate the selected procedure with a second predeclared outer seed and assess whether the gain persists. Then train the final fold ensemble, validate its schema/IDs/hashes, and evaluate through the official competition if the user chooses.

Historical V20/V080041 lineage blockers remain unresolved and are not needed to train this independent candidate. No claim is made that the new pipeline rebuilds the historical ensemble or reproduces its leaderboard score.
